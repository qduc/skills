# Skills

Agent skills published from a single locally maintained source.

Skills live under `skills/`. Each skill's `SKILL.md` describes its use.
Machine-specific configuration, Python caches, and the synced docx, pdf,
pptx, and xlsx skills are excluded. Skills sourced from
[mattpocock/skills](https://github.com/mattpocock/skills) are also excluded;
install those separately from upstream. Individual license files are retained.
This repository does not grant additional rights to third-party content.
